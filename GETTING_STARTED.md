### Short Description (LinkedIn, 500 chars)
```
Developed a high-fidelity web-based digital twin of the PUMA 560 robotic arm using Python, Streamlit, and Three.js. Features include real-time 6-DOF control, forward kinematics computation, interactive 3D visualization, trajectory recording with CSV export, and workspace analysis with manipulability heatmaps. Modernized legacy educational tools to create an accessible, browser-native simulation platform for robotics education.
```

```
🤖 Excited to share my latest project: A High-Fidelity Digital Twin of the PUMA 560 Robotic Arm!

Over the past few months, my team and I built an interactive web-based simulation platform that brings industrial robotics education to anyone with a browser.

🔧 Technical Highlights:
✅ Forward kinematics using Denavit-Hartenberg parameters
✅ Real-time 3D visualization with Three.js (60 FPS)
✅ Trajectory recording, workspace mapping, manipulability analysis
✅ Built with Python, Streamlit, NumPy, and Plotly

💡 Why it matters:
Traditional robotics labs cost $50K+ per unit. Our solution democratizes access — students worldwide can now experiment with a 6-DOF industrial robot arm for free.

🎯 What I learned:
• Robot kinematics and transformation matrices
• Full-stack development with modern Python frameworks
• 3D graphics programming and WebGL integration
• Creating educational tools with real impact
```
